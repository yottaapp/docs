# 自动化目标

自动化节点通过目标槽位访问具体程序或设备。工作流包不应固定绑定另一台电脑上的窗口身份；导入后，在本机
把同名或合适的目标槽位配置好即可。

## Windows 窗口

1. 在“设置 → 桌面应用”添加可执行文件。
2. 在“设置 → 自动化目标”新增 Windows 目标。
3. 选择应用，并设置标题/窗口类匹配方式。
4. 使用“检查当前窗口匹配”确认结果唯一或符合最上层选择策略。
5. 选择输入和截图后端并保存。

固定标题优先使用精确匹配；标题会变化时使用 RE2 正则。标题和窗口类同时填写时，两者都必须匹配。

## Android

Android 目标通过 ADB 设备序列号和应用包名定位。设备必须已连接并授权 USB 调试。模拟器重建或设备序列号
变化后，需要重新选择目标。

## 浏览器

浏览器目标通过 CDP endpoint 发现页面。启动浏览器的远程调试端口后，在设置中填写 endpoint、发现页面并
保存页面身份。页面关闭或调试地址不可达时，运行会报告目标未就绪。

## 配置即授权

用户保存的目标配置就是运行授权。Yotta 在每次 Run 中直接使用该目标，不会在每个节点前重复弹出授权确认。
因此请只配置你信任的程序、设备、网页和网络地址。

## 默认目标

在工作流编辑器选择默认自动化目标并保存。没有单独覆盖目标的节点使用工作流默认值。AI 可读取已保存的默认目标，并用它获取截图。

如果没有默认目标，AI 不会随意选中第一个配置。你可以先设置默认值，也可以在指令中说明要使用的目标。

## 鼠标校准

鼠标校准档中的 counts 表示原地旋转 360° 对应的原始鼠标计数。输入支持精确整数，例如 `1111`，不会按百位取整。不同软件或灵敏度可使用不同校准档。

## 窗口截图

截图遵循目标配置的捕获方式。窗口关闭、最小化或应用不支持所选方式时可能无法取得画面；先恢复窗口并检查目标状态。AI 查询目标和截图不会执行整个工作流。
