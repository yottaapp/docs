# 截图与坐标

**目标截图**获取指定自动化目标的画面，适合分析应用内的按钮和区域。**屏幕截图**获取整个 Windows 虚拟桌面，多个显示器会包含在同一画面中。

返回值包含图片、捕获时间、坐标空间、原始宽高和输出图片宽高。为了控制模型输入大小，图片可能等比例缩小。图片不会作为普通 base64 文字传给模型，而是使用图像内容传输。

## 换算位置

如果输出图片宽高为 `width`、`height`，原始宽高为 `sourceWidth`、`sourceHeight`：

```text
原始 x = 图片 x × sourceWidth / width
原始 y = 图片 y × sourceHeight / height
```

目标截图得到的是目标画面位置。屏幕截图还需加 `originX`、`originY` 才得到系统屏幕位置；副屏位于主屏左侧或上方时，原点可以是负数。

截图坐标不能不经转换就混用。使用节点时继续遵循节点合同声明的客户区、屏幕、像素或比例坐标。

## 画面不可用

没有默认目标时先配置目标；目标不可用时先检查窗口、设备或浏览器连接。屏幕截图当前支持 Windows，其他平台会返回明确的不可用结果，不返回虚构画面。
